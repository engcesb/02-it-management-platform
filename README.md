# 02-it-management-platform
Plataforma de governança, gestão de projetos de TI, workflows automatizados e integração de ITSM/Business.

### Conjunto de soluções voltado para a governança de TI, gestão de portfólio de projetos e eficiência operacional. Abrange ecossistemas de automação low-code/no-code (n8n, Make), integrações de ferramentas de gestão (Jira, Trello) e modelagem de processos alinhados a frameworks de governança e boas práticas da indústria.
